# Filtres Wireshark de base

| But | Filtre d'affichage |
|---|---|
| ARP | `arp` |
| DNS | `dns` |
| TCP | `tcp` |
| ICMP | `icmp` |
| HTTP | `http` |
| TLS | `tls` |
| hôte IPv4 | `ip.addr == 192.0.2.10` |
| port TCP | `tcp.port == 443` |
| retransmissions signalées | `tcp.analysis.retransmission` |

Les adresses sont documentaires. Adapter uniquement à son propre laboratoire.
