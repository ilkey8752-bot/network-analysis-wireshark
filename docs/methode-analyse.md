# Méthode d'analyse

1. Partir du symptôme et de l'heure exacte.
2. Identifier les hôtes et le protocole attendu.
3. Appliquer un filtre large, puis le réduire.
4. Suivre la chronologie sans conclure sur un paquet isolé.
5. Comparer attendu et observé.
6. Conserver les limites et hypothèses dans le compte rendu.
